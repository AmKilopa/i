# KlpInstall

KlpInstall настраивает чистую 64-разрядную Windows так, чтобы личные папки, загрузки, временные файлы, рабочие кэши и выбранные программы использовали отдельный диск вместо системного диска C:.

## Перед запуском

- Нужна Windows 10 версии 1809 или новее либо Windows 11.
- Диск `D:` должен уже существовать, быть локальным, фиксированным и отформатированным в NTFS.
- На диске `D:` должно быть не менее 50 ГБ свободного места.
- Для установки программ нужен интернет.
- Скрипт не создаёт разделы и не форматирует накопители.

## Быстрый запуск на чистом компьютере

1. Откройте страницу репозитория и скачайте файл [`install.bat`](https://github.com/AmKilopa/i/raw/main/install.bat).
2. Запустите скачанный файл двойным щелчком.
3. Подтвердите запрос контроля учётных записей Windows.
4. Дождитесь итогового отчёта и перезагрузите компьютер.

`install.bat` не требует заранее установленных Git, WinGet или PowerShell 7. Он использует встроенный Windows PowerShell 5.1, загружает недостающие файлы из этого репозитория и при необходимости восстанавливает WinGet.

При повышении прав `run.ps1` передаёт параметры через `-EncodedCommand`, поэтому пути к корню диска вроде `D:\` не повреждаются кавычками Windows. Если установка завершается ошибкой в окне администратора, окно остаётся открытым до нажатия Enter, чтобы сообщение можно было прочитать.

## Что настраивается

- Рабочий стол, Документы, Загрузки, Изображения, Музыка, Видео, Сохранённые игры, Снимки экрана и Плёнка камеры перенаправляются на `D:` через штатный Windows API.
- Существующие файлы сначала копируются на новый диск и проверяются. Исходники автоматически не удаляются.
- OneDrive останавливается, удаляется и блокируется системными политиками. Небольшая системная задача повторно применяет блокировку после крупных обновлений Windows.
- Edge и Chrome получают каталог загрузок `D:\Downloads`, а их профили и кэши переносятся на `D:`. Профиль Firefox также хранится на `D:`.
- Пользовательские и системные временные файлы направляются в `D:\KlpInstall\Temp`.
- Кэши Python, pipx, Poetry, NuGet, npm, pnpm, Yarn, Rust, .NET, Go, Gradle, Android, Playwright, Puppeteer, Cypress, Electron, Hugging Face, PyTorch, CUDA, Ollama, vcpkg, ccache и sccache направляются на `D:`.
- Файл подкачки и аварийные дампы Windows переносятся на `D:`, гибернация отключается, Storage Sense включается.
- В автоматическом режиме устанавливаются Python 3.12, Firefox, Node.js LTS, VS Code, Discord, Git, Telegram, Chocolatey, Spotify и pnpm.
- Программы и их управляемые профили размещаются в `D:\Program` и `D:\AppData`.
- Резервные копии настроек, журналы и итоговая проверка сохраняются в `D:\KlpInstall`.

Windows, драйверы, WinSxS, Microsoft Store, системные компоненты и небольшая часть служебных данных должны оставаться на C:. Перенос этих частей небезопасен, поэтому KlpInstall их не трогает.

Для программ, которых нет в списке KlpInstall, при последующей ручной установке всё равно нужно выбирать каталог на `D:`. Скрипт не меняет системный `Program Files` целиком, потому что это может повредить Windows и обновления программ.

Edge и Chrome показывают сообщение о том, что часть параметров управляется организацией. Это ожидаемо: Windows-программы используют локальные политики только для принудительного сохранения профилей, кэшей и загрузок на отдельном диске.

## Другие режимы

Интерактивный выбор компонентов:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -BasePath 'D:\.'
```

Только настройка папок и Windows, без установки программ:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Automatic -SkipApplications -BasePath 'D:\.'
```

Безопасный просмотр плана без изменения компьютера:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 -Automatic -SkipApplications -PlanOnly -BasePath 'D:\.'
```

`D:\.` автоматически нормализуется в `D:\` и используется в примерах, чтобы корневой путь не заканчивался обратным слешем непосредственно перед закрывающей кавычкой командной строки. Для другого несистемного диска используйте, например, `E:\.`.

## После завершения

Перезагрузка обязательна для окончательного применения новых путей личных папок, файла подкачки и политик OneDrive. Итоговый код `0` означает, что все выбранные этапы и встроенная проверка завершились успешно. При другом коде откройте последний файл в `D:\KlpInstall\Logs`.
